# Site font provenance

`inter-en-vi-variable.woff2` is the only webfont loaded by `../index.html`. It is a subset of the Inter variable font for this English/Vietnamese site, retaining normal style, optical-size and weight axes. It is licensed under the included [SIL Open Font License 1.1](OFL.txt).

The subset retains basic Latin, Vietnamese precomposed letters and combining marks, punctuation and symbols used on the site. The shipped binary's cmap was checked against the site's non-ASCII characters and an EN/VI NFC/NFD proof string. This coverage check does not replace browser review of mark placement and line wrapping. No other Inter font files are bundled.
