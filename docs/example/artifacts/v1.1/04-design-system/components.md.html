not listed here is out of scope and says so.

## States: declared, and honestly scoped

This is a static marketing page with no data, no forms, no network and no authentication.
The state matrix a product surface would carry does not apply, and inventing one would be
filler. What that means concretely:

| State | Status |
| --- | --- |
| Hover, focus-visible, active/pressed | **Implemented** on every interactive element |
| Pressed/checked (toggle, segmented, switch) | **Implemented**, with ARIA |
| Language switch (EN ⇄ VI) | **Implemented**, swaps `documentElement.lang` and all `data-i18n` nodes |
| Header scrolled | **Implemented** |
| Reduced motion | **Implemented**, plus a visible explanatory note |
| No-JavaScript | **Implemented** — everything renders; only the three script-driven rigs go inert, and their explanations are static text |
| Placeholder (install commands not yet live) | **Implemented** as an explicit labelled state |
| Loading · empty · error · validation · disabled · permission-denied | **Out of scope.** No data is fetched, no form is submitted, nothing can be empty or fail. Declared unreachable rather than mocked |

## Keyboard contract

21 tab stops, in DOM order, all with a visible 2px accent outline at 3px offset:

skip → wordmark → 5 nav links → EN → VI → 2 hero CTAs → 3 press buttons (rig A) → run
both (B) → 3 segmented buttons + reveal (C) → 2 switches (D).

No focus traps, no dialogs, no view changes, so no focus repositioning is required.

## Viewport contract

| Width | Composition change |
| --- | --- |
| ≥1080px | Full layout. Two-column section headers, four-column step rows, 2×2 rigs |
| <1080px | Section headers stack · step rows drop the leader and move artifacts under the body · rigs, trail, story, install, who and evidence all go single-column · spine becomes 4×2 |
| <720px | Nav links drop · spine becomes 2×4 |
| 390px | Verified composed, not squeezed: headline holds three lines at 34px, the plate stack keeps its overlap at a smaller scale, and no element overflows |
