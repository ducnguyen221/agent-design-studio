From DESIGN.md

Fixture Studio is an original, quiet system for tests: a light and a dark theme, surface panels on bg, and one blue accent accent for the primary action. It is a package that an audit can read and a code baseline that an audit can check it against.

  • Read order: Claude Design → README.md → tokens.json → components/*/README.md; other agents → DESIGN.md → tokens.json → canonical-map.json → components/
  • Owner: fixture author
  • Version: 0.1.0
  • Status: approved
  • Canonical by domain: brand → README.md; tokens → tokens.json; components → src/Button.js (see canonical-map.json)

Start here: Brand book, Button, Action feedback, Web surface rules, Icons.

Paths are relative to the fixture project root, one level above this folder. Extract and audit must leave this baseline unchanged. Intentional drift: the accent token here differs from the accent custom property in src/tokens.css. An audit must report both and keep the owner decision pending. Runtime, accessibility and token-to-render parity stay unverified until a browser run.

            Variants

            Primary only. The source declares one primary class: an accent fill with a white label. There is no secondary, disabled or loading variant.

            States
            • Default: accent fill, label type style.
            • Focus: a 3px outline, declared in the entry page.
            • Hover, disabled and loading: not implemented.

            The source sets padding and corner radius as fixed values in the entry page. The intended mapping is space-2 and space-3 for padding and radius-sm for the corner.

            Accessibility
            • Role button, from the native element.
            • Enter and Space activate it, as for any native button.
            • The visible label is the accessible name, so every button needs a meaningful label.
            • Runtime keyboard and screen reader behaviour is not verified here.

            Source: src/Button.js. Feedback after a click belongs to the pattern in patterns/ActionFeedback.md.
